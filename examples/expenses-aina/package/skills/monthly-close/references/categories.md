# Expense categories

| Category | Use for |
|---|---|
| food | Groceries, restaurants, coffee, delivery |
| transport | Taxi, train, flights, fuel, parking |
| housing | Rent, utilities, repairs |
| shopping | Clothes, electronics, household items |
| health | Medicine, doctor, fitness |
| entertainment | Movies, games, subscriptions, events |
| other | Anything that fits none of the above |
